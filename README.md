# make-computers-personal-again
There is no cloud; it's just someone elses computer.  So I compile thoughts and other semi sentient programs for creative autonomy, software ownership, and digital sovereignty, advocating for local-first, user-controlled, offline-capable workflows in modern computing.

# Make Computers Personal Again

A collection of thoughts, visuals, and ideas about reclaiming digital sovereignty in an age of platform dependency.

## 🎯 Philosophy

Computers were once tools of individual empowerment. Today, with the advent of server farms and a non-neutral nternet, much of computing has shifted into centralised cloud platforms where ownership, control, and creative sovereignty are increasingly abstracted away from the user.  it's harder to capture lightning in a bottle when someone else holds the proprietary lease on the glass... 

This repo explores what we lose—and what we can regain.

## 🧠 Contents

- Essays on personal computing
- Reflections on cloud dependency
- Digital artefacts (wallpapers, stickers, designs)
- Open ideas for reclaiming creative control
